# 2045 CHRONO STRIKER

2045년의 미래형 전투기 **XF-2045 Asterion**이 1945년으로 타임슬립하여 과거의 하늘과 바다를 지배해 나가는 설정의 HTML5 종스크롤 슈팅 게임입니다.

## 구성
- `index.html` : 메인 실행 파일
- `style.css` : 화면 스타일
- `game.js` : 게임 로직
- `assets/backgrounds/*.webp` : 5개 스테이지 배경
- `assets/sprites/*.webp` : 플레이어기, 적기, 군함, 보스, 총알, 폭발, 아이템 등 게임 자산

## 실행 방법
1. 압축을 해제합니다.
2. 폴더 내부의 `index.html`을 크롬/엣지 등 최신 브라우저에서 엽니다.
3. 또는 정적 사이트 호스팅에 폴더 전체를 그대로 업로드합니다.

## 조작
### PC
- 이동: 화면 위에서 마우스를 움직이면 버튼 없이 조종합니다. 방향키/WASD도 지원합니다.
- 폭탄: 게임 화면에서 마우스 왼쪽 클릭 또는 `X` / `B`
- 일시정지: `P` 또는 `ESC`
- 사격: 자동 발사

### 모바일
- 화면 드래그: 이동
- 우하단 `BOMB`: 폭탄 사용
- 우상단 `Ⅱ`: 일시정지

## 특징
- 5개 전장 / 5개 보스전
- 미래형 주인공기 + 1945년대 적기/군함/요새 조합
- WebP 그래픽 자산 사용
- 로컬 최고점수 저장
- 외부 라이브러리 없음

## 참고
- 본 패키지는 정적 사이트에서 바로 실행되도록 작성되었습니다.
- 이미지 자산은 고화질 생성 이미지를 기반으로 정리한 WebP 에셋입니다.

## 개발 검증
Node.js 22 이상에서 `node --check game.js` 및 `node --test tests/game.test.cjs`를 실행합니다.
브라우저 검사는 Playwright 1.62.1과 Chromium 설치 후, 저장소 루트에서 `python3 -m http.server 8765`로 서버를 열고 `node tests/browser.cjs`를 실행합니다.
GitHub Actions는 PR과 main 변경 시 동일한 검사를 실행합니다. 실제 Android/iOS 기기의 터치·오디오·전체화면은 별도 확인이 필요합니다.

## v2.3 전진 비행 · 전술 교신
- 지형이 위에서 아래로 흐르도록 배경 스크롤 방향을 교정했습니다.
- 마우스 호버 이동과 왼쪽 클릭 폭탄을 지원합니다. 모바일은 드래그 + BOMB 버튼을 유지합니다.
- 기존 고화질 WebP를 재사용해 서로 다른 외형과 공격 패턴을 가진 보스 5종을 구성했습니다.
- 극지 전선의 WHITE RAVEN은 대형 폭격기 기반 비행요새로, 교차 조준탄과 강화 시 호위기를 사용합니다.
- 모든 보스는 체력 50% 이하에서 공격 주기가 빨라집니다. 오른쪽 정보창에 이미지·공략·체력·전장 진행과 등장/강화/격파 대사를 표시합니다.
- ASTER 코파일럿은 전장 진입, 보스 접근, 피격, 보급, 폭탄, 클리어 상황을 안내합니다. 텍스트 기반 로컬 이벤트 안내이며 외부 LLM·음성 합성·API 키를 사용하지 않습니다.
- 교신은 전투를 멈추거나 포인터 입력을 막지 않으며, 중요한 경고를 우선하고 보급 알림은 간격을 제한합니다.
