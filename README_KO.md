# 2045 CHRONO STRIKER

2045년의 미래형 전투기 **XF-2045 Asterion**이 1945년으로 타임슬립하여 과거의 하늘과 바다를 지배해 나가는 설정의 HTML5 종스크롤 슈팅 게임입니다.

## 구성
- `index.html` : 메인 실행 파일
- `style.css` : 화면 스타일
- `game.js` : 게임 로직
- `assets/backgrounds/*.webp` : 5개 스테이지 배경
- `assets/sprites/*.webp` : 플레이어기, 적기, 군함, 보스, 총알, 폭발, 아이템 등 게임 자산

## 실행 방법
1. 압축을 해제합니다.
2. 폴더 내부의 `index.html`을 크롬/엣지 등 최신 브라우저에서 엽니다.
3. 또는 정적 사이트 호스팅에 폴더 전체를 그대로 업로드합니다.

## 조작
### PC
- 이동: 방향키 또는 WASD
- 폭탄: `X` 또는 `B`
- 일시정지: `P` 또는 `ESC`
- 사격: 자동 발사

### 모바일
- 화면 드래그: 이동
- 우하단 `BOMB`: 폭탄 사용
- 우상단 `Ⅱ`: 일시정지

## 특징
- 5개 전장 / 5개 보스전
- 미래형 주인공기 + 1945년대 적기/군함/요새 조합
- WebP 그래픽 자산 사용
- 로컬 최고점수 저장
- 외부 라이브러리 없음

## 참고
- 본 패키지는 정적 사이트에서 바로 실행되도록 작성되었습니다.
- 이미지 자산은 고화질 생성 이미지를 기반으로 정리한 WebP 에셋입니다.
